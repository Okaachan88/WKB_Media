# WKB_Media

Pictures and short animations for the Wakaba (WKB) addons' CurseForge pages.
These files are only here so the pages can show them. There is no code in this repository.

- `wrm/` : Wakaba Rotation Mirror
- `wkbp/` : Wakaba Palette
- `mpop/` : Wakaba_M+Pop
- `luramemo/` : Lura Memo
- `test/` : a tiny test picture (a plain test pattern)

Addons: [WKB_RotationMirror](https://www.curseforge.com/wow/addons/wakaba-rotation-mirror) / [WKB_Palette](https://www.curseforge.com/wow/addons/wakaba-palette)
